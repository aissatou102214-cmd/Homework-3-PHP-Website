# Homework 3 — Paws & Friends Dog Adoption

A beginner-friendly PHP website with a shared header and footer.

## Files
- `header.php` — shared page header and navigation
- `footer.php` — shared copyright and contact footer
- `index.php` — homepage and dog profiles
- `about.php` — adoption information
- `style.css` — website design

## Run locally
PHP must be installed. From this folder, run:

```bash
php -S localhost:8000
```

Then open http://localhost:8000/index.php in a browser.

Both content pages use `include 'header.php';` and `include 'footer.php';`.

This is a fictional demonstration website for a class assignment.
